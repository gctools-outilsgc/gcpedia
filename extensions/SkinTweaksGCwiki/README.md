## SkinTweaksGCwiki

This extension replicates several changes that used to be made in a custom version of the Vector skin, one change remains Vector-specific, others appear in all skins.

### What this extension changes

1. Adds a new sidebar section with links to gcaccount, gccollab, and gcmessage, different skins handle this differently but it shows up in all of them that display the regular sidebar.
2. Adds a Canada FIP type image at the top of every page, this show up in all skins the same way.
3. Adds some images used in config-gcwiki.php
4. For the 2010 / legacy vector skin only, adds an extra header element with GCwiki written on it, to keep the same look the custom Vector skin had before
